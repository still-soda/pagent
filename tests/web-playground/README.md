# Pagent Web 演练场

独立的 Vue + Vite 页面，用于在真实网页里演练 Pagent。通过侧边栏切换场景。

组件库为 Element Plus，图标来自 `@element-plus/icons-vue`。

## 启动

在仓库根目录：

```bash
pnpm dev:playground
```

或在本目录：

```bash
pnpm install
pnpm dev
```

默认打开 [http://localhost:5173](http://localhost:5173)。

## 场景

- **表单场景**：技术沙龙报名表，覆盖输入、选择、日期、开关、评分、滑块与校验提交。
